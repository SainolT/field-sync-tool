# 字段同步工具 v1.2.0

用于维护多张 XLSX 表之间的字段映射、批量同步和字段值替换。

## 启动

- 无 Python 环境：双击发布包中的 `字段同步工具.exe`。
- 有 Python 环境：运行 `python sync_gui.py`，或双击 `字段同步工具.vbs`。

首次启动会引导选择或新建工具表。工具表与数据表可放在同一目录及其子目录中。

## 主要功能

- 通过「映射组」登记不同表格中的同义字段。
- 按键字段对齐行，将源字段值同步到目标字段。
- 按映射组或匹配字段批量替换目标字段值。
- 预览改动、自动备份、公式保护和失败日志。

## 写入安全

- 只处理第 2 行起的数据区，表头不改。
- 使用 `xlsx_writer.py` 对 XLSX 内部 sheet XML 做局部修改，不整体重写工作簿。
- 只保存实际有改动的文件，每个文件每批次备份一次。
- 采用临时文件和原子替换，写入失败时原文件不替换。

## 源码运行依赖

```text
Python 3
openpyxl
tkinter
```

安装依赖：

```bash
pip install openpyxl
```

## 源码文件

- `sync_gui.py`：Tkinter 界面。
- `core.py`：配置、扫描、计划生成和执行编排。
- `xlsx_writer.py`：XLSX XML 局部写入器。
- `字段同步工具.vbs`：Windows 无控制台启动器。
