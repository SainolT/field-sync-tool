# 字段同步工具

用于关联性强、且具有多映射关系的多表格管理与配置。

一个基于 Python + openpyxl + tkinter 的 xlsx 字段映射管理工具：用一张「工具表」登记多个表格之间的同义字段（映射组），然后在图形界面里完成跨表字段同步和字段值翻译。适合管理多套结构相同、命名不同的配置表（如换皮项目的平行配置）。

## 下载与启动

**没有 Python 环境（推荐给大多数人）**

到 [Releases](../../releases) 下载最新版的 zip（含 `字段同步工具.exe` + `字段同步工具表.xlsx` 模板），解压后双击 exe 即可，无需安装任何环境。

**有 Python 环境（启动更快）**

单文件 exe 每次启动需要自解压，会慢几秒；如果你电脑上装了 Python，直接用脚本启动几乎是秒开：

```bash
pip install openpyxl
python sync_gui.py          # 或双击 字段同步工具.vbs（Windows 无黑窗启动）
```

要求：python.org 官方版 Python 3（自带 tkinter）+ openpyxl。

## 核心概念

工具目录下有一张「工具表」（默认 `字段同步工具表.xlsx`），包含：

- **总表**：登记表格清单（文件名称 | 表格名称）
- **字段表**：字段映射缓存（映射组 | 文件名称 | 表格名称 | 字段名）——同一映射组里的字段互为同义映射（如「作物名称」组里有 作物名称/茶树名称/茶树名）
- **使用说明**：完整图文说明

规则：数据文件按**工具表所在目录**查找，支持任意层级子目录；工具表格式的文件不会被误当数据表。

## 功能与操作

### 同步（同组搬值）

以一个表格的字段值为标准，按键字段对齐行，同步到其他表格的同义字段：

1. ① 选择「同步映射组」（要同步的字段组）
2. ② 选择「同步源字段」（组内各字段带位置标注，选一个作为数值标准）
3. ③ 勾选「被同步字段」（多选/全选）
4. ④ 选择「键映射组」（候选已按所选字段自动筛选，选 ID 类组）
5. 「预览」确认改动 → 「开始同步」

### 字段替换（跨组翻译）

把某列中填的 A 类值（如名称）按参照表批量翻译成 B 类值（如 ID），适合"ID 列里临时填了名称，批量翻回 ID"的场景：

1. ① 选择「被替换字段」：文件树 → 子表 → 字段逐级选择，可多选、跨子表累积；输入关键字则按完整路径平铺筛选（未登记的字段也能选）
2. ②「当前值是」+ ③「替换成」：声明翻译方向（两个映射组）
3. ④ 选择「参照表」（自动筛选出同时登记了两个组的表当字典）
4. 「预览」→「开始替换」

查不到对照的值保留原样并列进日志；已是目标值的单元格自动跳过。

### 登记字段 / 删除映射组

- 「登记字段」：文件树 → 子表 → 未登记字段逐级选择，加入已有映射组或输入新组名新建
- 「删除映射组」：整体删除一个组的所有登记（只删映射关系，不动数据表）

### 防护机制

- 启动时自动校验：工具表格式 + 全部映射有效性（失效映射会列出明细并询问是否清理）
- 所有批量操作先「预览」看改动清单，确认后才写入
- 写入前自动备份（默认在「字段同步备份」文件夹，可自定义目录）
- **表头永不被修改**，所有操作只写数据区（第 2 行起）

## 打包为 exe（自行构建）

```bash
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --clean --name 字段同步工具 \
  --exclude-module PIL --exclude-module lxml --exclude-module ssl \
  --exclude-module unittest --exclude-module doctest --exclude-module pydoc \
  --exclude-module turtle --exclude-module lib2to3 --exclude-module xmlrpc \
  --exclude-module multiprocessing --exclude-module concurrent sync_gui.py
```
