# 字段同步工具

## 简介

用于关联性强、且具有多映射关系的多表格管理与配置。用一张「工具表」登记多个 xlsx 表格之间的同义字段（映射组），在图形界面里完成跨表字段同步和字段值翻译。适合管理多套结构相同、命名不同的配置表（如换皮项目的平行配置）。

## 技术栈

- Python 3 + openpyxl（读表/计划）+ tkinter（界面，官方 Python 自带）
- 写表为自研 XML 外科手术（zipfile + 正则，见「写入实现」）

依赖安装：

```bash
pip install openpyxl
```

## 启动

**没有 Python 环境**：到 [Releases](../../releases) 下载最新 zip（含 exe + 工具表模板），解压双击 exe，零安装。

**有 Python 环境（启动更快）**：单文件 exe 每次启动要自解压会慢几秒，脚本几乎秒开：

```bash
python sync_gui.py          # 或双击 字段同步工具.vbs（Windows 无黑窗启动）
```

首次启动会引导选择或新建工具表（含「总表」「字段表」「使用说明」三个 sheet）。工具表和数据表放同一目录，支持任意层级子目录。

## 使用方法

### 同步（同组搬值）

以一个表格的字段值为标准，按键字段对齐行，同步到其他表格的同义字段：

1. ① 选择「同步映射组」（要同步的字段组）
2. ② 选择「同步源字段」（组内字段带位置标注，选一个作为数值标准）
3. ③ 勾选「被同步字段」（多选/全选）
4. ④ 选择「键映射组」（候选已按所选字段自动筛选，选 ID 类组）
5. 「预览」确认改动 →「开始同步」

### 字段替换（跨组翻译）

两种方式（子页签），共用「被替换字段」选择区（文件树 → 子表 → 字段，可多选/跨子表累积/关键字平铺筛选）：

- **按参照表（映射组）**：声明 当前值是/替换成 两个映射组，选一张同时登记了两组的表当字典；被替换列的当前值去参照表查，命中即替换。适合"ID 列里临时填了名称，批量翻回 ID"
- **按字段匹配**：选参照表格 + 匹配字段 + 取值字段；按目标表同行的匹配字段值去参照表对齐行，把取值字段的值写入被替换列（如按「道具名称」对齐，把「道具图标」写入「道具ID」列）。目标子表需有与匹配字段同名的列

### 登记字段 / 删除映射组

- 「登记字段」：文件树 → 子表 → 未登记字段逐级选择，加入已有映射组或输入新组名新建
- 「删除映射组」：整体删除一个组的所有登记（只删映射关系，不动数据表）

## 匹配算法

- **行对齐**：按键映射组的值匹配，各表用自己在组里登记的字段名取键值（同义不同名不影响，如 作物ID/茶树ID）；值比较做归一化（`1`、`1.0`、`"1"` 视为相同，去首尾空格）
- **源侧**：键重复取首次出现的行并提示数量；源值为空不同步（不会清空目标）
- **目标侧**：所有键值相同的行都会更新（一对多正常）
- **替换查表**：查不到对照的保留原样并列入日志；参照表键重复取第一行并警告；已是目标值的单元格自动跳过
- **公式保护**：源值是公式（含数组公式）不同步/不参照；目标单元格是公式或以 `=` 开头的文本（防公式注入）不覆盖；均有警告
- **扫描缓存**：按 路径+修改时间+大小 缓存表头解析结果，多文件场景下只有变化的文件才重新读取

## 写入规则

- 只改写数据区（第 2 行起），**表头永不修改**
- 只保存实际有改动的文件，没改的文件字节级不动
- 每个文件每批次：打开一次 → 备份一次（写盘前，保真）→ 完成全部修改 → 保存一次
- 备份默认在「字段同步备份」文件夹（可自定义），文件名带路径和时间戳，可按批还原
- 保存失败（如文件被占用）不会损坏原文件，日志按 成功/部分失败/失败 三级报告，计划改动与实际保存分开计数

## 写入实现

不用 openpyxl 整体读写（那会重写样式表、丢失图表与公式缓存值，可能破坏下游转表）。改为**外科手术式 XML 编辑**：

1. xlsx 本质是 zip；解析 `xl/workbook.xml` 与 `xl/_rels/workbook.xml.rels` 定位目标 sheet 的 XML 路径
2. 在 sheet XML 文本里只替换/插入目标 `<c>` 单元格节点，单元格样式属性（`s=`）原样保留；字符串用 `inlineStr` 写入，不动 sharedStrings.xml
3. zip 内其它条目字节级原样复制；先写临时文件再 `os.replace` 原子替换原文件

效果：除目标单元格的值外，文件的格式、样式、图表、其余内容全部保持原样。

## 打包

```bash
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --clean --name 字段同步工具 \
  --exclude-module PIL --exclude-module lxml --exclude-module ssl \
  --exclude-module unittest --exclude-module doctest --exclude-module pydoc \
  --exclude-module turtle --exclude-module lib2to3 --exclude-module xmlrpc \
  --exclude-module multiprocessing --exclude-module concurrent sync_gui.py
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `sync_gui.py` | 界面层（tkinter 窗口、页签、登记/删组对话框、启动引导） |
| `core.py` | 逻辑层（工具表与配置读写、扫描缓存、映射校验、变更计划生成、执行编排、日志模板） |
| `xlsx_writer.py` | 写入层（sheet XML 定位与单元格外科手术、原子保存） |
| `字段同步工具.vbs` | Windows 无控制台启动器 |
