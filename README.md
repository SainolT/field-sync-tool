# 字段同步工具

用一张「工具表」登记多个配置表（xlsx）之间的同义字段（映射组），在图形界面里完成跨表字段同步和字段值翻译。适合管理多套结构相同、命名不同的平行配置（如换皮项目）。

## 技术栈

- Python 3（tkinter 界面）
- openpyxl：读取 xlsx 结构与数据、生成变更计划
- 写入不经过 openpyxl，直接修改 xlsx（zip）内目标工作表的 XML

依赖安装：

```bash
pip install openpyxl
```

## 启动

```bash
python sync_gui.py          # 或双击 字段同步工具.vbs（Windows 无黑窗启动）
```

没有 Python 环境时，用 Releases 里的 exe，双击即用（单文件 exe 启动时需自解压，比脚本慢几秒）。

首次启动会引导选择或新建一张「工具表」（含 总表/字段表/使用说明 三个工作表）。工具表与数据表放同一目录，支持任意层级子目录；工具表格式的文件不会被误当数据表扫描。

## 使用方法

顶部操作栏：「登记字段」「删除映射组」「更换工具表」「设置备份目录」，底部为日志区（统一报告模板：配置 → 明细 → 警告 → 执行结果 → 汇总）。

### 同步（页签1）

把一个表格的字段值，按键对齐同步到其他表格的同义字段：

1. ① 选「同步映射组」（要同步的字段组）
2. ② 选「同步源字段」（组内字段带 文件|子表|字段名 位置标注，选一个作为数值标准）
3. ③ 勾选「被同步字段」（多选，可全选）
4. ④ 选「键映射组」（候选已按所选字段自动筛选，选 ID 类组）
5. 「预览」查看改动清单 →「开始同步」（需确认，写入前自动备份）

### 字段替换（页签2）

两个子页签共用「被替换字段」选择区（文件树 → 子表 → 字段逐级选择，可多选、跨子表累积；输入关键字切换为完整路径平铺筛选；未登记的字段也能选）：

- **按参照表（映射组）**：声明「当前值是」「替换成」两个映射组，选一张同时登记了两组的表当字典。被替换列的当前值去参照表查找，命中即替换。适合「ID 列里临时填了名称，批量翻回 ID」
- **按字段匹配**：选参照表格 + 匹配字段 + 取值字段。按目标表同行的匹配字段值去参照表对齐行，把取值字段的值写入被替换列（如按「物品名称」对齐，把「物品图标」写入「物品ID」列）。目标子表需有与匹配字段同名的列

### 登记字段

「登记字段」按钮 → 文件树 → 子表 → 未登记字段（多选，可关键字筛选）→ 选已有映射组或输入新组名新建 →「加入」→「保存」。同义字段要加进**已有**的组，新建组会和旧字段断开映射。「删除映射组」可整体删除一个组（只删映射，不动数据表）。

## 匹配算法

1. **行对齐**：按键映射组的值匹配行。各表用自己在组里登记的字段名取键值，同义不同名不影响（A 表的 `物品ID=202001` 和 B 表的 `素材ID=202001` 视为同一行）。值比较做归一化（`1`、`1.0`、`"1"` 相同，去首尾空格）
2. **源侧**：键重复取首次出现的行并提示数量；源值为空不同步（不会清空目标数据）
3. **目标侧**：所有键值相同的行都会更新（一对多是正常场景）；值已一致的单元格跳过
4. **替换查表**：查不到对照的保留原样并列进日志；参照表键重复取第一行并警告；已是目标值的单元格自动跳过；空单元格跳过
5. **公式保护**：源值是公式（含数组公式）的不同步/不参照；目标单元格是公式或以 `=` 开头文本（防公式注入）的不覆盖；均计入警告
6. **扫描缓存**：表头解析按 路径+修改时间+大小 缓存，只有变化的文件才重新读取

## 写入规则

- 只写数据区（第 2 行起），表头永不修改
- 只保存实际有改动的文件，没改的文件字节级不动
- 每个文件每批次：打开一次 → 写盘前备份一次（保真）→ 完成全部修改 → 保存一次
- 保存失败（如文件被占用）不损坏原文件；日志区分 成功/部分失败/失败，计划改动与实际保存分开计数

## 写入实现

xlsx 是 zip 包。写入时只替换 zip 内目标工作表的 XML：定位并改写目标单元格节点（样式属性原样保留，字符串以内联字符串写入、不动共享字符串表），zip 内其余文件（其他工作表、公式缓存值、样式、主题）字节级保留。与整表重写（openpyxl 保存）相比，不会丢失公式缓存值，不影响下游转表。

其他防护：

- 预览与写入分离，确认后才执行
- 写入前自动备份原文件（默认「字段同步备份」目录，可自定义；文件名带路径与时间戳，可按批还原）
- 先写临时文件再原子替换，中途失败原文件不损坏

## 打包为 exe

```bash
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --clean --name 字段同步工具 \
  --exclude-module PIL --exclude-module lxml --exclude-module ssl \
  --exclude-module unittest --exclude-module doctest --exclude-module pydoc \
  --exclude-module turtle --exclude-module lib2to3 --exclude-module xmlrpc \
  --exclude-module multiprocessing --exclude-module concurrent sync_gui.py
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `sync_gui.py` | 界面层（tkinter 窗口、页签、登记/删组对话框、启动引导） |
| `core.py` | 逻辑层（工具表与配置读写、扫描缓存、映射校验、变更计划生成、执行编排、日志模板） |
| `xlsx_writer.py` | 写入层（工作表 XML 定位与单元格外科手术、原子保存） |
| `字段同步工具.vbs` | Windows 无控制台启动器 |
| `工具配置.json` | 运行时生成：工具表路径、备份目录 |
| `扫描缓存.json` | 运行时生成：表格表头扫描缓存 |
| `字段同步备份/` | 运行时生成：写入前自动备份 |
